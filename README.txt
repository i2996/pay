근무기록 (설치형 웹앱)

이 폴더의 파일을 "새 GitHub 저장소"에 그대로 올리고 Pages를 켜면, 폰에서 '앱 설치'가 나와요.

주의: 메모 정리 앱을 올려 둔 저장소에 올리면 그 앱의 index.html 등을 덮어써요.
반드시 새 저장소(예: work)를 만들어서 올려 주세요.

올린 뒤 순서
1. 새 저장소 만들기(Public, README 켜기)
2. 압축을 푼 파일 8개를 전부 올리고 Commit changes
3. Settings > Pages > Deploy from a branch > main, / (root) > Save
4. https://내아이디.github.io/저장소이름/ 을 크롬에서 열고 '앱 설치'

기록은 열어 본 기기의 브라우저 안에만 저장돼요. 설정 맨 아래의 '내보내기'로 가끔 백업해 두세요.
